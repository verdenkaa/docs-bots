**[Контракт convert_document](./entrypoints.md#convert-document)** · [DTO](./contracts.md#dto)

Конвертер — подмодуль Gateway, не отдельный сервис. Возвращает UTF-8 Markdown и изображения для записи Gateway в S3.

## Порядок

1. Проверить содержимое и выбрать разрешённый обработчик. Неизвестный формат явно отклонить: расширяемая система не обещает поддержку всех файлов.
2. Сохранить порядок текста, заголовков, таблиц, значимые URL/операторы. Не переписывать весь текст моделью.
3. Извлечь изображения: OCR через recognize_text и описание схемы/интерфейса через describe_image в Model Gateway.
4. Назначить `uuid5(revision_id, "image:" + str(image_no))`, номера с 0 в порядке извлечения.
5. Поставить `![Описание](image://<uuid>)`; вернуть Markdown и байты/MIME/ImageRef изображений. Сам конвертер S3 не пишет.
6. Проверить совпадение наборов ID в Markdown и images. Описание экранировать по Markdown. Пустой результат не принимать.

Готовый Markdown проходит ту же проверку. Произвольный URL/путь картинки не является нашим image_id: разрешённый обработчик должен получить файл безопасным способом либо отказать. Нельзя скачивать произвольные URL или читать локальные файлы по ссылкам в документе.

## Исполнение

Оригинал находится только в ограниченном потоке/буфере вызова, на диск не записывается. Обработчик, которому требуется дисковый оригинал, не включаем без изменения этого решения. CPU-разбор работает вне event loop в управляемом процессе. Gateway ограничивает общий срок и останавливает зависшего исполнителя с потомками; одной отмены корутины недостаточно. Модельные вызовы имеют бюджеты внутри общего срока.

[MarkItDown](https://github.com/microsoft/markitdown) — ранее предложенный кандидат для текстовой части; у него есть потоковый convert_stream, но это само по себе не гарантирует все нужные свойства каждого обработчика. Допуск конкретного обработчика зависит от тестов таблиц, изображений, памяти и отсутствия записи оригинала. Установленная библиотека сама по себе не подтверждает эти свойства.

## Проверка профиля

| Вход | Ожидание |
| --- | --- |
| Заголовки и таблицы | Читаемый Markdown без потери значимых значений. |
| Скриншот/схема | OCR/описание, байты изображения и совпадающий плейсхолдер. |
| Картинка без текста | Пустой OCR допустим; VLM может дать содержательное описание. |
| Повреждение/неизвестный тип | Отказ, а не частично принятая редакция. |
| Зависание/превышение памяти | Управляемая остановка без accepted. |

Форматы, модели и лимиты — конфигурация испытанного профиля. До его проверки готовность приёма не объявляем.
