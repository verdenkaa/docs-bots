RAG API принимает обновления Telegram через webhook или long polling и отправляет готовые ответы. Оба режима передают работу в одну очередь. Приём заканчивается после регистрации вопроса, ответ приходит в чат позже.

- Как устроен шлюз, чем владеет и как работает с RabbitMQ. [Модуль](./module/index.md)
- Какие HTTP-ручки нужны и кто их вызывает. [Эндпоинты](./endpoints/index.md)
