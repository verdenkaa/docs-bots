# Дополнительные доверенные сертификаты

Корневой Compose монтирует этот каталог в `/etc/rag/certs` только для чтения.
Для GigaChat положите сюда публичный CA PEM из официального источника и задайте
`GIGACHAT_CA_BUNDLE=/etc/rag/certs/<имя-файла>.crt` в корневом `.env`.

Проверка TLS включена по умолчанию. При `GIGACHAT_VERIFY_SSL_CERTS=false`
дополнительный CA не используется. Файлы сертификатов не попадают в Git.
В этом каталоге не должны находиться приватные ключи и другие секреты.

Источник и инструкция: https://developers.sber.ru/docs/ru/gigachat/certificates
