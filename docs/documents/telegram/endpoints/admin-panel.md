# <span className="operation-badge operation-badge--get">GET</span> `/admin`

## Назначение и доступ

Административная панель Support. Вход HTTP Basic по ADMIN_LOGIN/ADMIN_PASSWORD
через HTTPS; публичный origin задаётся TELEGRAM_WEBHOOK_URL. Credentials и
Origin проверяются сервером, Principal не принимается из JSON.

## Что принимает

GET без тела и query. Заголовок Authorization: Basic с настроенными credentials.

## Бизнес-логика

Показывает до 100 последних тикетов, ссылки на их историю, форму операторского
ответа и закрытие. Позволяет менять enabled для Telegram username и читать
метрики полуоткрытого периода. Начальная и конечная даты формы метрик обозначают
полночь UTC; конечная дата исключается. Данные выводятся как текст через DOM.
Форма ответа сохраняет client_message_id до подтверждения, чтобы повтор после
обрыва не создавал новую реплику. Публичная страница тикета продолжает писать
как посетитель; операторская форма использует административную ручку.

## Что отдаёт

200 OK, text/html; charset=utf-8, Cache-Control: no-store.

## Ошибки и повторы

| HTTP | Причина | Действие |
| --- | --- | --- |
| 401 | Нет или неверны credentials | Войти; ответ содержит WWW-Authenticate. |
| 503 | ADMIN_LOGIN/ADMIN_PASSWORD не настроены | Исправить конфигурацию. |

Мутации панели проверяют Origin и возвращают 403 при несовпадении. Операторское
сообщение повторяется с прежним client_message_id; изменение допуска и закрытие
идемпотентны. Ошибки БД дают 503 без текста внутренних исключений.
