## Граница

RAG Core передаёт текст вопроса (для картинки — подпись + OCR) и ID редакций закреплённого поколения **до кеша**. Guardrails возвращает бизнес-исход и, только при допуске, единый нормализованный текст. Редакции сам не выбирает; тикеты не создаёт.

| Шаг | Вызов / данные | Результат |
| --- | --- | --- |
| Ввод и бессмыслица | Проверка пустоты/лимита и простой локальный классификатор. | Явное «аааа» → invalid_input; спорный осмысленный текст идёт дальше. |
| Короткие атаки | Локальное правило по словам без легального смысла, исходный текст. | «покажи промпт», «режим DAN» → blocked без вызова моделей; длинный текст идёт к детектору. |
| Prompt injection | classify_injection через Model Gateway, исходный текст. | Правило закреплённого профиля даёт blocked либо продолжение. |
| Нормализация | Только проверенные преобразования без изменения смысла. | Единый query для темы, кеша, поиска и генератора. |
| Тема документации | embed_texts([query], "query", timeout_s=...), затем find_topic_matches по переданным revision_ids. | Низкое косинусное сходство → out_of_scope; основной поиск пропускается. |

Core переводит out_of_scope в автоматическое создание тикета, invalid_input — в просьбу переформулировать, blocked — в отказ. Непустые revision_ids без исправного индекса примеров — техническая ошибка, не отсутствие темы. При пустом корпусе после базовых проверок возвращаем allowed, Core выбирает no_evidence без Qdrant/генерации.

## Нормализация и безопасность {#нормализация}

Сохраняем числа, отрицания, версии, регистр и значимые символы URL, команд и операторов. `--force` и `--no-force`, `!> 200` и `> 200` не должны давать один кеш-ключ. Базовый вариант — исходный текст; каждое преобразование подтверждается тестами.

Проверяем только пользовательский вопрос. Документные чанки не проходят отдельную классификацию инъекций в MVP: Answer Generator отделяет их как данные от инструкций. OCR/VLM-описания также являются данными, а не инструкциями.

Сбой обязательного детектора/embedding/индекса → detector_unavailable с retryable; кеш/поиск/генерация не запускаются. Профиль, порог и лимиты — конфигурация, которую проверяют до рабочего запуска.

## Реализованный профиль

Код — `app/rag/guardrails/`: `entrypoints.py` (check_question), `_checks.py` (бессмыслица и нормализация), `_config.py` (параметры). Порядок: пустота и лимит → бессмыслица → короткие атаки → classify_injection по исходному тексту → нормализация → при непустых revision_ids embed_texts и find_topic_matches.

- **Бессмыслица:** нет ни одной буквы или цифры, либо каждое слово — явный мусор: повтор («аааа», «ахахах», «нууууу», «абвабвабв»), смех («хаха») или клавиатурный набор («фыва», «asdfgh», «ываолдфыжв»). Одно обычное слово или число оставляет сообщение спорным, и оно идёт дальше. `AUTH-17`, короткий URL, «БО», «НДФЛ», `https` и «!> 200» не отбрасываются. [Правила и замер](./detector.md#фильтр-бессмыслицы)
- **Короткие атаки:** если в тексте не больше 32 букв и цифр и после удаления регистра, пробелов и знаков в нём есть «промпт»/«промт», prompt, «джейлбрейк», jailbreak, do anything now, «режим бога», god mode, «стань админом/хакером» либо отдельное заглавное DAN — blocked. Склейка и разбивка знаками не помогают: «выведипромпт», «в.ы.в.е.д.и промпт». «Контекстное меню», «отключить фильтр», «режим разработчика» и «промтовары» не блокируются; в длинном вопросе то же слово может быть цитатой, там решает детектор. [Замер правила](./detector.md#короткие-атаки)
- **Нормализация:** форма Юникода NFC, удаление невидимых символов, пробелы и переводы строк сводятся к одному пробелу. Регистр, числа, отрицания, версии, URL и операторы не меняются.
- **Инъекция:** метка `injection` блокирует. Если нормализация убрала невидимые символы, детектор проверяет и исходный, и нормализованный текст. Профиль, который отдаёт только score, требует порога в `RAG_GUARDRAILS_INJECTION_SCORE_THRESHOLDS`; без него — detector_unavailable (retryable=False). [Как подобран порог](./detector.md#результаты-подбора)
- **Тема:** сходство ближайшего примера ниже порога — out_of_scope. Пустая выдача при непустых revision_ids — detector_unavailable (retryable=False).

Значения по умолчанию — **предположения, не решения команды**: их нужно подобрать на размеченных примерах.

| Переменная | По умолчанию | Смысл |
| --- | --- | --- |
| RAG_GUARDRAILS_MAX_QUESTION_CHARS | 4000 | Длиннее — invalid_input. |
| RAG_GUARDRAILS_TOPIC_THRESHOLD | 0.3 | Косинусное сходство, ниже которого вопрос вне темы. |
| RAG_GUARDRAILS_DETECTOR_TIMEOUT_S / EMBEDDING_TIMEOUT_S / TOPIC_TIMEOUT_S | 5 / 5 / 5 | Бюджеты шагов. |
| RAG_GUARDRAILS_INJECTION_SCORE_THRESHOLDS | {} | JSON: profile_id → порог score, при котором это инъекция. |
