# <span className="operation-badge operation-badge--get">GET</span> `/tickets/{case_id}`

## Назначение и доступ

Публичная ссылка: любой посетитель читает созданный тикет без входа, даже если он не автор Telegram-вопроса. Общего публичного списка нет.

## Что принимает

case_id: UUID в пути; тела нет. Query:

| Поле | Ограничения | Назначение |
| --- | --- | --- |
| limit | int, 1..100, по умолчанию 50 | Размер страницы. |
| before_message_id | int 1..9223372036854775807, необязательно | Исключающий курсор более ранних сообщений. |

Без курсора показаны последние limit реплик в хронологическом порядке.
Ссылка «Предыдущие сообщения» передаёт next_cursor; новая реплика не сдвигает границу уже выбранной страницы.

## Бизнес-логика

Вызвать get_ticket(case_id,limit,before_message_id). Показать снимок одного вопроса/ответа и сообщения. Только open/closed; HTML экранируется. Форма посетителя отправляет на публичный маршрут messages.

## Что отдаёт

200 OK, text/html; charset=utf-8. Страница TicketView; закрытый тикет доступен только для чтения.

## Ошибки и повторы

422 — неверный UUID/тело; 404 — тикет отсутствует или ещё не создан; 503 — БД/коммит недоступны. Нет зависимости от ADMIN_LOGIN/ADMIN_PASSWORD и проверки employees.
