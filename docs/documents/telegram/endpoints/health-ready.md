# <span className="operation-badge operation-badge--get">GET</span> `/health/ready`

## Назначение и доступ

Среда запуска вызывает `GET /health/ready` по внутреннему адресу, чтобы проверить, готов ли RAG API принимать новые вопросы.

## Что принимает

GET без тела, параметров и специальных заголовков.

## Бизнес-логика

1. Проверяем, что RAG API и выбранный входной адаптер готовы к приёму, а Runtime может регистрировать вопрос и outbox в PostgreSQL.
2. Проверяем, ниже ли число незавершённых запросов настроенного лимита. Если RabbitMQ временно недоступен, приём возможен, пока эти условия выполнены. Публикация продолжится из outbox.

## Что отдаёт

`200 OK` с пустым телом, когда можно принять новый вопрос. `503 Service Unavailable` с пустым телом, когда приём временно невозможен.

## Ошибки и повторы

| HTTP-код | Код ошибки, если предусмотрен | Когда возникает | Действие клиента |
| --- | --- | --- | --- |
| `503` | — | Приём ещё не готов, PostgreSQL недоступен для записи или достигнут лимит накопления. | Дождаться успешной проверки перед передачей нового трафика. |
