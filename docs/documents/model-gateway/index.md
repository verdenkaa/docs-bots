## Граница

Model Gateway — общий Python-модуль `rag.model_gateway` для embedding, reranker, детектора инъекций, генерации, OCR и VLM-описания. Каждый вызов идёт через выбранный адаптер: локальную модель либо удалённый API, в том числе собственный сервер инференса. Модуль не требует отдельного контейнера. Qdrant хранит и ищет векторы; веса моделей в его том не загружаем.

| Владелец бизнес-логики | Что вызывает в Model Gateway | Что решает самостоятельно |
| --- | --- | --- |
| Guardrails | `classify_injection`, `embed_texts` с purpose=query | Инъекция, бессмыслица, щадящий порог темы по примерам Qdrant, нормализация и бизнес-исход. |
| Searcher | `embed_texts` с `purpose="query"`, затем при включённом шаге `rerank` | Поиск в Qdrant по разрешённым редакциям, порядок и отбор фрагментов. |
| Ingestion Gateway · Converter | `recognize_text`, `describe_image` | Разбор документа, плейсхолдеры и описание изображений; Gateway пишет S3. |
| Ingestion Worker | `embed_texts` с document/query, `generate` | Чанки, примеры допустимых вопросов, сохранение наборов и публикация обоих индексов. |
| Answer Generator | `generate` | Промпт, бюджет контекста, проверка JSON, меток источников и перевод в `GenerationResult`. |
| RAG Core | `recognize_text` | Только текст из картинки сотрудника; подпись + OCR сохраняются перед Guardrails. |
| Runtime | `start_models`, `close_models` | Выбор конфигурации, запуск нужных ролей и готовность процессов. |

Model Gateway проверяет технический формат ответов, сохраняет соответствие входов и выходов, ограничивает параллелизм и время вызова. Он не читает PostgreSQL, не публикует сообщения RabbitMQ, не выбирает редакции и не принимает решение о допуске вопроса. RAG Core вызывает бизнес-модули и организует OCR входящего изображения через recognize_text; VLM-анализ скриншота пользователя не выполняется.

## Как заменить реализацию

Для каждой роли выбираем один binding при запуске процесса. Разрешено смешать локальные эмбеддинги и API генерации. Отсутствие роли reranker допустимо только при явно выбранном профиле поиска без reranker. Обязательную модель нельзя молча заменить заглушкой, отключить или переключить на другого провайдера при ошибке. Для изолированного теста Runtime может подставить детерминированный адаптер с тем же DTO.

Конфигурация провайдеров остаётся внутри сборки Runtime и Model Gateway. Внешние точки входа Guardrails, Searcher, Ingestion и Answer Generator сохраняются. [Трассировка параметров](../rag-core/flow.md#model-calls).
