## Граница

RAG Core передаёт текст вопроса (для картинки — подпись + OCR) и ID редакций закреплённого поколения **до кеша**. Guardrails возвращает бизнес-исход и, только при допуске, единый нормализованный текст. Редакции сам не выбирает; тикеты не создаёт.

| Шаг | Вызов / данные | Результат |
| --- | --- | --- |
| Ввод и бессмыслица | Проверка пустоты/лимита и простой локальный классификатор. | Явное «аааа» → invalid_input; спорный осмысленный текст идёт дальше. |
| Prompt injection | classify_injection через Model Gateway, исходный текст. | Правило закреплённого профиля даёт blocked либо продолжение. |
| Нормализация | Только проверенные преобразования без изменения смысла. | Единый query для темы, кеша, поиска и генератора. |
| Тема документации | embed_texts([query], "query", timeout_s=...), затем find_topic_matches по переданным revision_ids. | Низкое косинусное сходство → out_of_scope; основной поиск пропускается. |

Core переводит out_of_scope в автоматическое создание тикета, invalid_input — в просьбу переформулировать, blocked — в отказ. Непустые revision_ids без исправного индекса примеров — техническая ошибка, не отсутствие темы. При пустом корпусе после базовых проверок возвращаем allowed, Core выбирает no_evidence без Qdrant/генерации.

## Нормализация и безопасность {#нормализация}

Сохраняем числа, отрицания, версии, регистр и значимые символы URL, команд и операторов. `--force` и `--no-force`, `!> 200` и `> 200` не должны давать один кеш-ключ. Базовый вариант — исходный текст; каждое преобразование подтверждается тестами.

Проверяем только пользовательский вопрос. Документные чанки не проходят отдельную классификацию инъекций в MVP: Answer Generator отделяет их как данные от инструкций. OCR/VLM-описания также являются данными, а не инструкциями.

Сбой обязательного детектора/embedding/индекса → detector_unavailable с retryable; кеш/поиск/генерация не запускаются. Профиль, порог и лимиты — конфигурация, которую проверяют до рабочего запуска.
