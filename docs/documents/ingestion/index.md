## Граница

В контейнере `worker` работают Gateway и последовательный Worker. Gateway принимает документ через Python-вход, вызывает свой конвертер, сохраняет изображения в S3 и готовый Markdown во временном томе. После коммита задания и outbox загрузка принята. Worker получает `job_id` и индексирует уже готовый Markdown. Оригиналы не сохраняем. Публичный транспорт загрузки пока не выбран; HTTP-ручку этим контрактом не вводим.

~~~mermaid
flowchart LR
 A["Адаптер с проверкой доступа"] --> G["Gateway / Converter"]
 G -->|"изображения"| S3[("S3")]
 G -->|"Markdown + манифест"| V[("worker_spool")]
 G -->|"редакция + outbox"| P[("PostgreSQL")]
 P --> R["Queue Relay в core"] --> MQ[("RabbitMQ · ingestion.jobs")]
 MQ --> W["Worker"]
 V --> W
 W -->|"чанки + примеры темы"| Q[("Qdrant")]
 W -->|"публикация обоих наборов"| P
~~~

Модели вызываются через Model Gateway, хранилища — через Runtime. Документ не отправляется в сценарий ответа RAG Core.

## Новый документ или новая редакция

| Идентификатор | Что обозначает |
| --- | --- |
| `document_id` | Один документ. Вход None создаёт новый; для замены передаём ранее выданный ID. |
| `revision_id = job_id` | Одна загрузка и задание; повтор Worker не меняет ID. |
| `chunk_id` | UUIDv5 редакции и номера чанка с 0. |
| ID примера темы | UUIDv5 редакции и строки `question:<номер>` с 0. |
| `image_id` | UUID изображения S3, назначенный Gateway. |
| Поколение корпуса | Версия всего опубликованного набора редакций. |

Имя файла — подпись, а не идентификатор: автоматического определения замены по имени нет.

## Публикация

Worker сохраняет подготовленные чанки и примеры вопросов, записывает оба набора Qdrant, проверяет полноту и лишь затем публикует редакцию транзакцией PostgreSQL. Ошибка оставляет прежнюю редакцию видимой.

### Пример замены редакции

| Момент | Qdrant | Что читают вопросы |
| --- | --- | --- |
| Поколение 41 | Чанки и примеры R1. | R1. |
| Подготовка R2 | R1 и невидимые точки R2. | Всё ещё R1. |
| Коммит поколения 42 | Обе редакции до уборки. | Новые вопросы — R2; закрепившие 41 — R1. |

После завершения убираем Markdown/манифест/подготовленные наборы. Уборка старых точек не удаляет изображения, готовые ответы и метаданные HTML-заглушки. [Владение](../architecture/data-and-versions.md) · [Worker](./worker.md)
