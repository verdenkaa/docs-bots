# <span className="operation-badge operation-badge--get">GET</span> `/tickets`

## Назначение и доступ

Web-интерфейс собственной тикет-системы. Employee видит свои обращения, operator/admin — все. Личность берётся только из доверенного web-входа в Principal. Способ входа пока открыт; пока адаптер не подключён, защищённая ручка возвращает 503 auth_not_configured, а не доверяет user_id/role из тела.

## Что принимает

| Query | Тип | Смысл |
| --- | --- | --- |
| limit | int, 1..100, по умолчанию 50 | Максимум созданных тикетов. |

GET без тела.

## Бизнес-логика

Вызвать list_tickets(actor,limit); права применяются до лимита. Показать список открытых/закрытых тикетов по убыванию request_id. Для admin интерфейс содержит управление допусками и доступ к метрикам.

## Что отдаёт

200 OK, text/html; charset=utf-8. Страница списка, пустой список допустим.

## Ошибки и повторы

| HTTP | Причина | Действие |
| --- | --- | --- |
| 401 | Нет проверенной сессии/личности. | Войти выбранным способом. |
| 403 | Допуск отозван. | Обратиться к администратору. |
| 422 | Неверный limit. | Исправить параметры. |
| 503 | Вход не настроен или PostgreSQL недоступен. | Подключить вход / повторить позже. |
