**[Точки входа RAG API](./entrypoints.md)** — сигнатуры, параметры, форматы результата и примеры.

RAG API — шлюз Telegram в контейнере `core`. Он принимает обновления, регистрирует вопросы, получает готовые результаты и доставляет их в Telegram. Поиск и генерацию ведёт RAG Core. Связь с ним идёт через RabbitMQ. [Маршруты архитектуры](../../architecture/message-flow.md)

| Операция | Вход | Результат |
| --- | --- | --- |
| Принять обновление | Telegram Update с текстом вопроса и данными чата. | Принятый запрос и запись outbox для `rag.questions`. Повтор обновления относится к существующему запросу. |
| Получить готовый результат | Уведомление из `rag.results`. | RAG API читает итог и назначение доставки через Runtime. |
| Доставить результат | Сохранённый ответ с источниками, отказ или технический исход. | Сообщение в чат и зафиксированный исход попытки. |

RAG API отвечает за дедупликацию входящих обновлений, порядок приёма в чате, подготовку сообщения и лимиты отправки. PostgreSQL хранит данные этих этапов. Queue Relay публикует уведомления из outbox. [Приём и доставка через очередь](./queue-processing.md)

При включённой интеграции RAG API читает `TELEGRAM_BOT_TOKEN` из окружения `core`. Токен используется для вызовов Telegram Bot API в обоих режимах. Секрет для проверки входящих webhook-запросов задаётся отдельно. ## Два способа приёма

| Режим | Как приходит обновление | Что нужно от среды |
| --- | --- | --- |
| Webhook | Telegram отправляет обновление по HTTPS в RAG API. | Доступный Telegram HTTPS-адрес, подходящая настройка TLS и секрет webhook. [Ручка webhook](../endpoints/telegram-webhook.md) |
| Long polling | RAG API сам получает обновления через Telegram Bot API `getUpdates`. | Исходящий доступ к Telegram и один активный получатель обновлений на бота. [Telegram Bot API](https://core.telegram.org/bots/api#getupdates) |

Для каждого бота включаем один режим. Выбор сделаем по условиям кейса и развёртывания. Оба режима используют общий приём обновлений и одинаковую доставку ответа. [HTTP-ручки](../endpoints/index.md)
