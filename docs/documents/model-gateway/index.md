## Граница

Model Gateway — общий Python-модуль `rag.model_gateway` для эмбеддингов, reranker, детектора инъекций и генерации текста. Каждый вызов идёт через выбранный адаптер: локальную модель либо удалённый API, в том числе собственный сервер инференса. Модуль не требует отдельного контейнера. Qdrant хранит и ищет векторы; веса моделей в его том не загружаем.

| Владелец бизнес-логики | Что вызывает в Model Gateway | Что решает самостоятельно |
| --- | --- | --- |
| Guardrails | `classify_injection` | Проверки ввода, порог детектора, допуск, нормализация и исход `detector_unavailable`. |
| Searcher | `embed_texts` с `purpose="query"`, затем при включённом шаге `rerank` | Поиск в Qdrant по разрешённым редакциям, порядок и отбор фрагментов. |
| Ingestion Worker | `embed_texts` с `purpose="document"` | Разбиение текста, ID чанков, запись и публикация редакции. |
| Answer Generator | `generate` | Промпт, бюджет контекста, проверка JSON, меток источников и перевод в `GenerationResult`. |
| Runtime | `start_models`, `close_models` | Выбор конфигурации, запуск нужных ролей и готовность процессов. |

Model Gateway проверяет технический формат ответов, сохраняет соответствие входов и выходов, ограничивает параллелизм и время вызова. Он не читает PostgreSQL, не публикует сообщения RabbitMQ, не выбирает редакции и не принимает решение о допуске вопроса. RAG Core продолжает вызывать бизнес-модули; напрямую модельные операции ему не нужны.

~~~mermaid
flowchart LR
  C["RAG Core"] --> G["Guardrails"]
  C --> S["Searcher"]
  C --> A["Answer Generator"]
  W["Ingestion Worker"] --> M["Model Gateway"]
  G --> M
  S --> M
  A --> M
  S --> Q["Runtime · Qdrant"]
  W --> Q
  M --> L["Локальная модель в процессе"]
  M --> R["Внешний API / сервер инференса"]
~~~

## Как заменить реализацию

Для каждой роли выбираем один binding при запуске процесса. Разрешено смешать локальные эмбеддинги и API генерации. Отсутствие роли reranker допустимо только при явно выбранном профиле поиска без reranker. Обязательную модель нельзя молча заменить заглушкой, отключить или переключить на другого провайдера при ошибке. Для изолированного теста Runtime может подставить детерминированный адаптер с тем же DTO.

Конфигурация провайдеров остаётся внутри сборки Runtime и Model Gateway. Внешние точки входа Guardrails, Searcher, Ingestion и Answer Generator сохраняются. [Трассировка параметров](../rag-core/flow.md#model-calls).
