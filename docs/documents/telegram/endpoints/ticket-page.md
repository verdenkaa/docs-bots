# <span className="operation-badge operation-badge--get">GET</span> `/tickets/{case_id}`

## Назначение и доступ

Сотрудник открывает свой тикет; operator/admin могут открыть созданный тикет. Личность берётся только из доверенного web-входа в Principal. Способ входа пока открыт; пока адаптер не подключён, защищённая ручка возвращает 503 auth_not_configured, а не доверяет user_id/role из тела.

## Что принимает

case_id: UUID в пути. GET без тела и query.

## Бизнес-логика

Вызвать get_ticket(actor,case_id), показать снимок одного исходного вопроса/ответа и дальнейшие сообщения. Только open/closed считаются созданным тикетом. Данные экранируются, исходные промпты не выводятся.

## Что отдаёт

200 OK, text/html; charset=utf-8, страница TicketView с формой разговора.

## Ошибки и повторы

| HTTP | Причина | Действие |
| --- | --- | --- |
| 401 | Нет проверенной личности. | Войти. |
| 404 | Тикет отсутствует, чужой или ещё не создан. | Не раскрывать чужие данные. |
| 422 | Некорректный UUID. | Проверить адрес. |
| 503 | Вход не настроен / БД недоступна. | Повторить после восстановления. |
