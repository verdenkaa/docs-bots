# <span className="operation-badge operation-badge--get">GET</span> `/health/live`

## Назначение и доступ

Среда запуска вызывает `GET /health/live` по внутреннему адресу, чтобы проверить, отвечает ли HTTP-процесс RAG API.

## Что принимает

GET без тела, параметров и специальных заголовков.

## Бизнес-логика

Ручка отвечает из процесса RAG API. Проверки PostgreSQL, RabbitMQ и Telegram в этот вызов не входят.

## Что отдаёт

`200 OK` с пустым телом.
